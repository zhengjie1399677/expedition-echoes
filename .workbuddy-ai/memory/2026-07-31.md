## 远征余响：dev 模式 base 路径下图片 404

- 现象：用户报"首页图片资源引用错误"。首页是 `src/ui/pages/Town.tsx`，引用的图 `town-hub-v3.png`、`central-market-v1.png` 文件本身存在，`npm run build` 产物在 `vite preview` 下访问也 200。
- 根因：`vite.config.ts` 里 `base = '/expedition-echoes/'`，资源前缀由 `prefixRuntimePublicAssets` 插件在 **build** 阶段（`apply: 'build'` + `renderChunk`）注入。dev 模式该插件根本不跑，Town.tsx 编译后 src 还是裸 `/assets/...`，dev server 只在 `/expedition-echoes/assets/...` 提供这些文件，所以 dev 访问首页时所有图全 404。
- 修复：把插件拆成 `transform`（dev/build 都跑，把 `/assets/` → `${import.meta.env.BASE_URL}assets/`）+ `renderChunk`（仅 build，把模板字面量收成 `/expedition-echoes/assets/`）。已验证两端都正确。
- 经验：项目里 `base` 不为空时，凡是写死的 `/assets/...` 字符串字面量都得依赖这个插件；以后改资源路径或新加页面要意识到这一点。排查 404 时优先用 `curl` 探 dev server 实际返回的 src 路径是否带 base。
