# 《远征余响》界面行为与美术生产规范

## 产品形态

- 本项目是嵌入式游戏，不是由纵向内容块组成的普通网页。
- 桌面端与移动端都必须在当前视口内形成一个完整游戏舞台。
- 页面本身不得无限向下延伸；需要查看更多内容时，只允许指定面板内部滚动。
- React 负责界面、导航、存档和 LLM 交互；Phaser 负责远征中的场景、动画、镜头、粒子与音频。
- 即使 LLM 不可用，所有游戏规则、导航和远征流程仍须完整运行。

## 导航行为

- 城镇地图是非战斗功能的唯一主导航。
- 酒馆、宿舍和城门通过地图中的地点进入，不在顶部重复提供入口。
- 设置是系统级功能，放在右上角，不作为地图地点。
- 子页面提供“返回城镇”；点击游戏标题也可返回城镇。
- 酒馆必须进入独立页面，不得在地图下方展开网页式长面板。
- 远征完成或撤退后返回城镇地图。

## 固定舞台与滚动

- 应用根节点占满 `100dvh`，浏览器正文禁止滚动。
- 顶栏高度由内容决定，剩余空间全部交给当前游戏界面。
- 城镇地图、宿舍和战斗舞台默认不产生页面滚动。
- 酒馆队员列表、设置列表等可能溢出的内容，应在各自面板内部滚动。
- 战斗 HUD、地图和日志必须在同一个视口中可见，不得要求玩家上下翻页操作一回合。
- 移动端通过重新排版、缩放和局部滚动适配，不得简单变成长网页。

## 地图热点

- 地点标签应像地图注记一样融入背景，不使用明显矩形卡片、玻璃面板或大面积底色。
- 默认只显示文字、用途和小型定位标记。
- 悬停只能改变光点、文字亮度或极轻微光晕，不得突然出现另一套卡片样式。
- 交互热区可以大于视觉标记，但不可用可见底板表达热区。

## 整体美术方向

- 青春日式幻想冒险风，约六头身，年轻但不幼儿化，不使用写实成年佣兵比例。
- 采用清晰线稿、简化结构、平涂与少量分级阴影，避免写实金属、皮革和肌肉质感。
- 角色使用明亮职业配色；环境相对低饱和，以保证角色可读性。
- 酒馆、宿舍、城镇与远征必须属于同一个世界，不得出现写实背景与动漫角色互相拼贴。
- 可以参考用户提供图片的温暖空气感与青春幻想氛围，但不得复刻其中人物、服装、构图或识别性元素。

## 战斗画面

- 横版舞台，三人队伍同时站场，场景和距离关系是主体。
- 角色实际可见高度不应长期超过战斗区域高度的约三分之一。
- 前景、中景、远景必须清晰分层，角色脚下要有可信的地面位置。
- 动作采用约 12 FPS 的序列帧；镜头、根位移、粒子和界面以实时帧率运行。
- 攻击动作中的前进由 Phaser 世界坐标控制，序列帧只表现身体动作，禁止“角色迈步但原地不动”。
- 命中反馈至少包含关键帧停顿、受击动作、位移或击退、音效/粒子和适度镜头反馈。

## 动画资产生产

- 禁止让生成器把多个紧贴人物直接画在一张图后再等分裁切。
- 每个关键帧应独立生成和抠图，保留足够安全边距。
- 每帧独立检测可见边界，并以脚底与身体中心建立统一锚点。
- 通过工具在生产末端打包精灵图和帧元数据，而不是把生成画布直接当作精灵图。
- 新角色先完成静态设定、场景合成验证和单个动作样片，通过后再批量生产。
- 废弃原型不得继续作为新美术的约束；正式资产必须使用版本化文件名。

## 内容优先级

1. 远征战斗达到完整、可重复游玩的功能品质。
2. 城镇地图与酒馆/宿舍形成完整往返流程。
3. 宿舍与 LLM 情感互动增强。
4. 扩充任务、补给、角色和远征内容。
