## 7. 平衡缺口与后续关注（来自 GDD §14）

| 缺口 | 现状 | 建议 |
| --- | --- | --- |
| 敌人意图池 | 未进入 enemies.json | 按 GDD §16.8 配置（attack/charge/guard/pressure） |
| 蓄力封顶 | 无常量 | 建议 `BALANCE.chargeMaxLayers = 2` |
| 战斗数值压力感 | 高 HP 敌人伤害偏低 | 意图系统落地后观察 scout/gatekeeper 蓄力威胁是否足够 |

| 医师职业 | 无招募、无平衡 | 待 M4 角色制作时再平衡 |

## 8. 调整流程

1. 修改本文 → 同步 `src/domain/config.ts`（BALANCE）或对应 JSON。
2. 若改动影响战斗/经济/成长，补充/更新 `gameEngine.test.ts`、`combat.test.ts` 对应用例。
3. `npm test` 全绿 + `npm run build` 通过。
4. 回填本文"版本"与变更记录。
