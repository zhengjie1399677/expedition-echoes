# 战斗人偶资源管线

## 目标

让新角色、时装、武器与饰品的加入成本接近“替换资源包”，而不是重新制作所有动作帧。

## 表现层分工

- 酒馆、宿舍与 LLM 互动使用高质量角色插图。
- 战斗使用约六头身的模块化人偶。
- 战斗人偶使用职业骨架、外观皮肤与装备附件三个层级组合。

## 人偶槽位

每个职业骨架最多使用以下槽位：

1. 基础躯干与下装。
2. 头部与发型。
3. 前后手臂。
4. 前后腿部。
5. 主手武器。
6. 副手装备。
7. 披风、围巾、头发等次级运动附件。

## 可复用规则

- 新角色优先复用已有职业骨架，仅替换脸、发型、配色、服装皮肤和附件。
- 新时装只替换服装皮肤与附件。
- 新武器只替换武器槽位，并可附带少量动画参数。
- 只有新增职业或非人骨架时，才需要新建动作集。
- 同一人偶动作由根位移、骨架姿势和附件延迟组成；禁止整张人物图上下漂浮。

## 锚点与动作

- 双脚与根节点始终固定到场景地面基线。
- 待机只改变胸肩、头部、头发、围巾和武器的局部姿势。
- 攻击的实际前进与返回由 Phaser 世界坐标控制。
- 命中时以关键帧停顿、受击反应和镜头/特效表达冲击。

## 资源格式

- 原始部件表使用纯色键背景。
- `scripts/extract_rig_parts.py` 根据 alpha 连通块裁出部件，并生成可复查的 JSON 清单。
- 任何自动裁边后的部件都保留原始表和清单，供人工命名、确认槽位和调整锚点。
- 只有经过人工确认的部件清单才可以进入运行时人偶定义。

## 当前原型

`pipeline-assets/rigs/lan-vanguard-v1/parts-sheet-v1.png` 是先锋人偶的首张部件表。它目前只验证资产分离与自动裁边流程，不替换战斗中的正式角色。该目录属于资产管线产物，存放在 public/ 之外，不进入游戏运行时构建。
